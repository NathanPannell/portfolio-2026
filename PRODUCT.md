# Product

## Purpose

Show, in a few minutes of scrolling, that Nathan Pannell builds things for real people, tests them with real users, and builds an AI community. The site should be fun to use in its own right, because that is the claim it is making.

## Audience

People who might work with Nathan, join AI Build Night, or try one of the products: community members, collaborators, employers, and directors.

## Positioning

The line is "I build for real people." Each project names who it is for: builders, casts, explorers, creators, and the game is just for fun.

Move away from "outdoorsy nature app builder". Parkdex stays on the site as a game, not as the identity.

## Hierarchy

1. **AI Build Night** is the main thing right now.
2. **Offbooked** could really become a business. Give it the biggest set piece.
3. **Parkdex** is fun. Let it be playful.
4. **Play by the Sandbox** is a website Nathan designed for Mello's event.
5. **Not Quite My Tempo** is a game Nathan made for the fun of it. Its door and its own window give it the same standing as the rest, without a real-people's-problem angle it doesn't have.

## Scope

In: the five worlds, a link index, contact. Out: résumé, blog, CMS, contact form, project archive. The old writing and smaller projects are on production and in git history.

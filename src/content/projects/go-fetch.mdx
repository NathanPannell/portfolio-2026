Go Fetch is a semantic-search REST API with signup, login, PDF upload, and natural-language search across a personal document library.

The system splits the work across Flask, Celery, Redis, MongoDB, MinIO, and a dedicated embedding service. I built it to find the practical limits of a distributed search system, not just to make a demo work for one person on a laptop.

There is no frontend. The interesting part is the architecture, the load behaviour, and the agentic workflow I used to move from an issue to a reviewed pull request.

Go Fetch is a REST API with signup, login, PDF upload, and natural-language search across a personal document library. There is no frontend. The project is about the system underneath.

## What I built

I split the work across Flask, Celery, Redis, MongoDB, MinIO, and a dedicated embedding service, then used load tests and profiling to find the real bottlenecks.

## Result

Median search latency fell from 1,500ms to about 57ms at the ten-user baseline. Throughput rose from 0.09 to 26.1 requests per second, and the failure rate fell from double digits to zero. Moving embeddings into one sidecar also reduced 16 model copies to one and freed about 1.4GB of memory.
